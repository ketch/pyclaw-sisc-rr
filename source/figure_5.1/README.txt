ABOUT THIS EXPERIMENT
===============
Figure 5.1 shows the profiling results of a weak scaling experiment for an Euler application run on the Shaheen supercomputer
at KAUST. This experiment was computed over a range of 1, 4, 16, 64, 256, 1024, 4096, 16384 and 65536 cores.
The script makefig.py in this directory will produce the figure using data from the profiles in ./experiment/profile
